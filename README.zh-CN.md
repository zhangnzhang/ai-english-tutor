# ai-english-tutor

[English](README.md) | 简体中文

一个让 AI 变成有记忆的英语陪练的 Skill。每次开工先读你的错题本，一次只讲一个点，用短练习组反复练，每道题都批改、每道错题都给原因，再把错误、生词和进度写回普通的 Markdown 文件。

为 Claude 写的（作为 Skill）。任何能读 Markdown 指令、能改文件夹里文件的 AI 助手应该也能用，但我只在 Claude 上用过。

## 解决什么问题

直接让 AI 教英语，每次对话都从零开始：讲得多、练得少，不记得你昨天错在哪，出的选择题干扰项没人会选。

## 它做什么

- **从你的文件开始。** 先读水平档案、错题本、生词本，从"下一步"接着教。
- **用你自己犯过的错当错误选项。** 你写过 *dose has*、*did went*，它们就会出现在选项里，每道选择题都在逼你认出自己的错。
- **以练为主。** 每条规则先讲核心加两个例句，然后一组约 8 题，选择和填空各一半。
- **认真批改。** 给正确数、每题的完整正确句，每道错题下面一句为什么错。
- **间隔复习。** 学会的点在 1、3、7、14、30 天后回来抽查，错了打回第 1 天。
- **生词反复用。** 拼错的词和阅读里摘的表达会被放进后面的题里，用满 20 次再问你还记不记得。
- **兼容语音输入。** 读音相近的真实单词按识别错误处理，不是单词的拼法才算你的拼写错误。
- **不替你做。** 不替你写作文，不给范文让你背，不把它的估分当真实成绩。
- **出题自查。** 一份针对 AI 出题常见问题的检查清单：两个正确选项、没有时间信号、答案总在前几个位置、母语提示把人带向错误形式。

看[示例](examples/session.md)和[真实踩过的坑](skills/ai-english-tutor/references/pitfalls.md)。

## 现状

这是我每天备考雅思在用的方法，用了大约三周后整理出来的。我还没有参加考试，所以没有分数能证明它有效。我能保证的是：这里的每个坑、以及大部分规则，都来自一次真实出了问题并改掉的练习。较长的复习间隔是通用的间隔重复做法，我用的时间还不够长，没验证到。有成绩后我会补上。

## 安装

**Claude Code：** 把 `skills/ai-english-tutor/` 复制到 `~/.claude/skills/`（或项目的 `.claude/skills/`）。

**Claude 应用：** 把 `ai-english-tutor` 文件夹打成 zip，在设置里作为 Skill 上传。记忆文件需要放在能保留的地方，比如项目或连接的文件夹。

**其他助手：** 把整个 `skills/ai-english-tutor/` 文件夹给它，用 `SKILL.md` 作为指令。

然后建一次记忆文件：

1. 把 `references/` 里的四个模板复制到你学习用的文件夹，改名为 `learner-profile.md`、`error-log.md`、`vocab-list.md`、`back-translation.md`，删掉标着 `(example, delete)` 的示例行。跳过这一步也可以，第一次开工时 AI 会自己建。
2. 填好 `learner-profile.md` 开头：你的目标、母语，以及几条关于你生活的信息（用来造例句）。
3. 说一句："继续学英语。"

这几个文件就是记忆。放在固定位置，每次开工让 AI 先读它们。

## 文件

```
skills/ai-english-tutor/
├── SKILL.md                              # 流程、讲解、出题、批改
└── references/
    ├── learner-profile-template.md       # 目标、水平、路线、成绩、下一步
    ├── error-log-template.md             # 按状态管理的错误 + 间隔复习表
    ├── vocab-list-template.md            # 要反复用的词和使用次数
    ├── back-translation-template.md      # 第二天回译的段落
    └── pitfalls.md                       # 真实练习里出过的问题和改法
examples/
└── session.md                            # 一轮完整的出题和批改（虚构学习者）
```

## 说明

- 示例里的母语是中文，因为我是中文母语。Skill 本身不绑定任何语言或考试。
- 如果按某本语法书的单元顺序学，Skill 要求 AI 自己写讲解和题目，不照搬书里的内容。
- 备考时，正式的阅读和听力训练请用官方真题。AI 写的文章只用来打基础。
