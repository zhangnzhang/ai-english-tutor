# Error log

> Every recurring mistake, managed by status. When writing questions, at least half the set targets "top priority" and "needs work". Two correct sets in a row moves an item up one level.

## Statuses

- 🔴 **Top priority**: wrong three times or more, or just learned and not stable. Test every session.
- 🟡 **Needs work**: knows the rule, still slips.
- 🟢 **Mastered**: correct in recent sets. Spot-check occasionally.
- ⚪ **Not yet drilled**: seen in speaking or writing, no set written for it yet.
