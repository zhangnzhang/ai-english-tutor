# Vocabulary list

> Words to keep reusing. Each practice set puts 3–4 of them into its sentences, least-used first. One appearance in a set counts as one use.

## Rules

- **Where words come from**: the learner says "add X"; words they misspell in practice are added automatically (real-word speech-recognition slips do not count); about five expressions from each reading.
- **Counting**: update the counts after each graded set, together with the error log.
- **At 20 uses**: ask "do you still remember X?". Yes: move it to "Mastered". No: reset to zero.
- Word forms (spend / spent / spending) count as one word. Put the tricky part in "Watch out".
